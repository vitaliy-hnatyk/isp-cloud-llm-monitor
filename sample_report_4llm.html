Interpretation and limitations

A failure is a failed application/protocol check, not necessarily an ISP outage. SSH validates the SSH server banner without authenticating. HTTPS validates TLS certificates using Python's default trusted certificates. HTTP/HTTPS success means a 2xx/3xx status (redirects are not followed). DNS sends a UDP A-record query directly to the selected DNS server and requires a nonempty successful answer. ICMP uses the system ping executable, which may be blocked by firewalls. TCP success means the TCP connection was accepted; it does not validate an application service. LLM checks call OpenAI-compatible APIs or the native Anthropic Messages API: the models mode measures listing rather than inference, and generation modes may incur provider charges. API keys and generated response text are not written to CSV or HTML. *Variation is the mean absolute change between consecutive successful samples, not standardized network jitter. Use Ethernet, compare multiple independent public targets, and check your local gateway before attributing failures to an ISP. Amazon/Azure global probes reach public website/CDN services, not a particular cloud region; regional TCP probes use published AWS S3 and Azure Monitor endpoints, which can have access controls or routing behavior independent of your ISP.
